## 核心结论

1. **闲鱼是生态级流量入口**——全品类可卖，月活 2.34 亿（2026.6），约为第 2–10 名总和的 8 倍，核心能力是「被看见」。
2. **转转与拍拍严选用质检换信任**——2025 年转转关闭 C2C 转向 C2B2C「官方验」，是手机、家电等高单价 3C 的最优解。
3. **多抓鱼证明「品类内效率」的价值**——图书赛道 63% 垂直份额，但月活仅 32.4 万（约闲鱼的 1/722）；服装已成为其核心盈利支柱。
4. **得物（95 分）是特殊参与者**——以新品潮品为基本盘，二手属战略延伸，是否计入「二手平台」存在口径争议。
5. **爱回收的能力外溢值得留意**——2026 年 6 月上海荟聚开出全国首家运动主题店，把 3C 质检能力迁移到球拍品类，用 X 光机检测暗伤。

> 一句话：**「品类内的效率」比「平台的绝对大小」更值得优先考虑。**
